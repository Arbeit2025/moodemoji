# きもち絵文字メーカー（moodemoji）

日本語の気持ち・文章を入力すると、その気分に合った絵文字の並びを返す小さなツールです。

## 使い方

- 文章を入力して **絵文字にする** を押すと、気分に合った絵文字の並びが表示されます。
- 「すごく」「とても」などがあると並びが長く、「ちょっと」「少し」などがあると短くなります。
- 同じ文章を入れると、いつも同じ並びが出ます（入力のハッシュで決定的に選んでいます）。
- **コピーする** ボタンで、できた並びをコピーできます。
- 辞書に当たらない文章でも、ニュートラルな並びを返します（空振り表示にはなりません）。

対応する気分：うれしい／楽しい／悲しい／怒り／疲れた／眠い／お腹すいた／ドキドキ／びっくり／不安／リラックス／やる気／感謝（同点の気分は2つまで並びます）

判定はキーワード辞書の単純なスコアリングです。文章の意味を理解しているわけではありません。

## 技術構成

Python / Flask の単一ファイル構成（app.py）。判定はキーワード辞書のスコアリングで、外部通信は行いません。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m pytest
```

※ テストでは外部通信を行いません（辞書マッチング・強さ・決定性・フォールバックと、画面の表示だけを検証します）。

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。
